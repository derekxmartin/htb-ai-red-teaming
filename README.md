# AI red-teaming study assets

This repository currently contains model and archive assets associated with a learning exercise. It does not yet contain an authored walkthrough, a reproducible evaluation, or evidence of model-security findings.

The learning goal is to understand how model inputs, outputs, and evaluation boundaries affect the interpretation of AI red-teaming results. No claim of independent model authorship or validated security performance is made.

## Asset and sharing status

The model files and split archives need a provenance and redistribution-rights review. This repository does not grant a license to third-party models, training material, or course assets. Obtain required materials from their official source under the applicable terms. Do not assume that a public download link establishes permission to redistribute an asset.

## What a useful study example should include

A future authored example should identify the learning objective, source and license of each required model, setup versions, synthetic prompts, expected and observed outcomes, failure cases, and limitations. Those results have not yet been documented here. Keep real credentials, private datasets, and restricted course answers out of examples and commits.
